# 祝：小林子17岁生日快乐 · 生日空间 V3

一场可以直接触碰的银蓝色生日星空。平时由蛋糕、星座和月光构成画面，生日祝福只在隐藏演出里由粒子写出。保留全屏场景，常驻控制只有声音、留影、暂停三个图标；底部手势提示会自动消失。

## 本地打开

在现代浏览器中打开同目录的 `index.html`。请完整保留 `assets` 文件夹；分享压缩包时先解压再打开。所有脚本、纹理和 OC 素材均随文件附带，不依赖 CDN、远程字体、账号或构建工具。此版本仅为本地交付，没有发布到公网。

## 直接与空间互动

| 动作 | 空间反馈 |
| --- | --- |
| 拖动 | 环视空间，手指经过处留下星屑 |
| 拖出一段轨迹 | 留下短暂的银蓝色 SVG 光迹，与三维星屑和触点波纹叠合 |
| 轻触空处 | 释放星光与水波；WebGL 画面在触点周围产生轻微折射 |
| 轻触月亮 | 隐藏彩蛋：月面闪耀，地面泛起月光涟漪并召来流星 |
| 点亮五颗晶体星 | 逐颗亮起并连线，集齐后触发生日演出；随后自动复位，可重复玩 |
| 轻触光蝶 | 唤出完整 OC 幻影，约 11 秒后淡出；再次触碰可收回 |
| 双击／双点空处 | 召唤流星雨和光点绽放 |
| 长按 | 蓄力后让蛋糕散开，粒子依次组成「小林子」和「祝：小林子17岁生日快乐」，伴随流星与烟花，最后回到蛋糕 |
| 滚轮／双指 | 拉近、拉远；三维演出期间镜头会适当退开以容纳祝福 |
| 相机图标 | 生成当前画布的 PNG 下载请求；文件名含生日祝福，实际保存方式由浏览器决定 |
| 声音图标 | 开启本地合成的环境音和互动音；默认关闭 |
| 暂停图标 | 暂停／继续动态空间 |

键盘：方向键环视，空格／Enter 许愿，1–5 点亮对应星点，O 唤醒角色，F 流星雨，S 留影，R 回到蛋糕，M 声音，P 暂停／继续。暂停时可留影及切换声音，场景手势停止响应。

## 场景与文件

- `assets/space.js`：镜头、触摸和键盘控制、演出流程、辉光合成、触点折射、粒子绽放、声音和留影。
- `assets/sculpture.js`：多层粒子蛋糕、装饰及烛火；主场景使用字形采样生成的重组目标。
- `assets/dedication.js`：「小林子」与完整祝福的粒子字形目标，以及绕着蛋糕运行的银蓝光丝。祝福不会常驻画面，只在粒子彩蛋演出时显现；字形取自设备上的中文衬线字体，不同设备会有细微差异。
- `assets/encounters.js`：五颗互动晶体星、连线、光蝶与流星池。
- `assets/portrait.js`：从立绘像素生成 OC 粒子，让粒子从四周汇聚成角色；随后以较低亮度淡入抠背景后的立绘，隐藏时粒子反向散开。Canvas 降级场景保留简化的二维聚合效果。
- `assets/atmosphere.js`：月亮、程序星云、镜面地面、波纹、花瓣、星尘、空间光轨与月面闪光。
- `index.html` 与 `assets/space.js`：手势驱动的 SVG 光迹。
- `assets/oc-portrait.webp`：适配深色空间的完整 OC 图片；`oc-portrait-data.js` 为同一图片的内嵌副本，便于本地离线加载。
- `assets/vendor/`：本地 Three.js 与 MIT 许可证。

WebGL 初始化失败或上下文丢失时会进入简化 Canvas 场景，保留生日粒子演出、可点星点、光蝶、OC、流星、手势及留影。简化场景的空间深度、光影和折射效果不同。系统开启「减少动态效果」时会减弱持续运动与粒子扩散。

## 验证范围

已检查全部应用脚本语法、本地资源引用、粒子目标数据及完整演出状态。Node 模拟环境覆盖桌面、手机、减少动态效果和 Canvas 降级四种配置；验证长按、名字到完整祝福再复原、拖动、双指衔接、取消、暂停、隐藏恢复、点星及复位、OC 开关、双击流星、键盘与留影请求。额外使用 Three.js 投影及射线进行移动端星点位置和命中检查，覆盖四种屏幕尺寸及三个缩放级别。

以上使用真实 Three.js 对象图和模拟渲染器；字体采样、图片加载和下载使用测试替身。没有完成真实浏览器、GPU、微信内置浏览器或手机实机视觉验收，也没有验证最终导出的 PNG 内容。测试通过表示控制逻辑和数据检查通过，不等同于画面效果实测。
